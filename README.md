# Ankit Sharma — Portfolio Website

A modern, responsive personal portfolio website built using **HTML, CSS and JavaScript**.

The website showcases my education, technical skills, project experience, certifications and professional experience.

## 🚀 Features

- Modern dark UI
- Responsive design
- Mobile navigation menu
- Smooth scrolling
- Scroll reveal animations
- Skills section
- Education timeline
- Project showcase
- Certifications section
- Professional experience
- Contact section
- GitHub and LinkedIn links

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
